💸 UPI Transaction Data Analysis Dashboard
📌 Project Title
UPI Transaction Analysis Dashboard using Power BI

🎯 Purpose
This project focuses on analyzing UPI (Unified Payments Interface) transaction patterns across various banks in India. It aims to uncover insights from 20,000 transaction records, helping businesses or analysts identify trends in payment modes, customer behavior by age, transaction volumes, and city-wise distribution.

🛠 Tech Stack
Power BI – for interactive dashboard creation

Power Query Editor – for data transformation and shaping

DAX (Data Analysis Expressions) – for calculated columns and measures

Microsoft Excel – as the original data source

📊 Data Information
The dataset contains 20,000 UPI transactions and includes key columns:

Customer Age

Age Group

Transaction Amount

Bank Name (Sender & Receiver)

City

Payment Mode / Method

Transaction Time

Currency

💼 Business Impact & Key Features
Provides insights into which banks handle the most UPI traffic.

Identifies preferred payment modes and customer demographics.

Helps in regional marketing analysis based on city-wise data.

Supports decision-making for transaction time-based offers or load balancing.

Key Features Implemented:
Data Profiling & Cleaning using Power Query.

Slicer customization (size, position, and syncing across pages).

Age Group column added for grouped demographic insights.

Interactive Visuals: Line charts, matrix views, and multiple graph types.

Conditional Formatting on visual elements for clarity.

Bookmarks & Navigation for improved user experience.

Page-level navigation to separate different analysis perspectives.
